# 🌸 Обучающее приложение по математике в R Studio 💙

_Математика · Статистика · Финансы — в одном приложении_

## ✨ Что умеет приложение

### 🧮 Математические задачи
- Вычисление производных различных функций
- Анализ в заданной точке

### 📊 Статистика
- Описательные статистики (среднее, медиана, дисперсия)
- Построение гистограмм и boxplot
- Корреляционный анализ

### 💰 Финансовые расчёты
- Сложный процент
- Аннуитетный платёж (ипотека)
- NPV проекта

## 🛠 Технологии

- **R** — язык программирования
- **Shiny** — фреймворк для веб-приложений
- **ggplot2** — визуализация данных
- **bslib** — современный дизайн

## 🚀 Как запустить

1. Установи **R** и **RStudio**
2. Установи пакеты:
```r
install.packages(c("shiny", "ggplot2", "bslib", "bsicons"))
